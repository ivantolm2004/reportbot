# ReportBot

ReportBot превращает выгрузку продаж в небольшой проверяемый отчёт прямо в браузере. Он действительно читает CSV, нормализует строки и рассчитывает показатели; график и карточки KPI получают данные из отдельного аналитического ядра.

[Открыть анализатор](https://ivantolm2004.github.io/reportbot/)

## Путь данных

```text
CSV → parseCsv() → нормализованные строки → analyzeSales() → KPI + дневной ряд
```

Обязательные колонки — `date` и `amount`. `order_id` и `returned` необязательны. Поддерживаются запятая и точка с запятой, quoted cells, decimal comma и UTF-8 BOM.

В отчёте считаются:

- выручка без возвращённых строк;
- число уникальных заказов;
- средний чек как выручка / число заказов;
- доля возвратов по строкам;
- выручка по дням для графика.

## Воспроизвести результат

Загрузите [`examples/sales.csv`](examples/sales.csv) в live demo. Пример специально содержит возврат: его строка участвует в доле возвратов, но не увеличивает выручку.

```bash
npm test
```

Тесты отдельно проверяют оба разделителя, decimal comma, ошибки колонок, KPI и пустой набор. Функциональное ядро — [`src/analytics.js`](src/analytics.js), схема потока — [ARCHITECTURE.md](ARCHITECTURE.md).

## Ограничения импорта

Это клиентский CSV-анализатор, а не хранилище отчётов: данные не отправляются на backend и история не сохраняется. Парсер не поддерживает перенос строки внутри quoted cell и не читает XLSX. Подключение Google Sheets/CRM, расписание отчётов, PDF и отправка в Telegram/email остаются следующими интеграционными слоями.

Для локального запуска откройте `index.html`; внешние зависимости не нужны.
