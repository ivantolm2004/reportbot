# ReportBot

Демонстрация сервиса, который превращает CSV/Excel с продажами в понятный отчёт и отправляет ключевые выводы по расписанию.

## Возможности демо

- KPI по выручке, заказам, среднему чеку и возвратам;
- переключение периодов и интерактивный график;
- имитация импорта CSV;
- блок автоматически найденных отклонений;
- адаптивная вёрстка.

## Коммерческая версия

Импорт Excel/CSV, подключение Google Sheets и CRM, расчёты на Python/pandas, хранение истории, PDF-отчёты и доставка в Telegram или email.

## Запуск

Откройте `index.html` в браузере. Зависимости не требуются.
