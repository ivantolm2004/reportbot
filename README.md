# ReportBot

Работающий клиентский CSV-анализатор: читает реальные данные продаж, валидирует строки и пересчитывает KPI и график прямо в браузере. Аналитическое ядро отделено от UI и покрыто автоматическими тестами.

## Возможности демо

- KPI по выручке, заказам, среднему чеку и возвратам;
- переключение периодов и интерактивный график;
- настоящий импорт CSV с запятой или точкой с запятой;
- расчёт выручки, уникальных заказов, среднего чека и возвратов;
- блок автоматически найденных отклонений;
- адаптивная вёрстка.

## Формат данных и тесты

Обязательные колонки: `date`, `amount`. Дополнительные: `order_id`, `returned`.

npm test
